### ◆ About

I'm a Linux and cloud infrastructure engineer. My background is in Linux
administration across enterprise environments — keeping Ubuntu and CentOS
systems patched, monitored and available — followed by systems engineering
with Python automation and cloud support work in AWS environments.

I care about infrastructure that is reproducible, observable and secure by
default, and about runbooks clear enough that someone else can operate what I
build. I'm deepening my work in infrastructure as code, containers and CI/CD,
and I build privacy-conscious, human-centered tools along the way —
[JobForge](https://github.com/Likhithpadige-cyber/jobforge) is the current one.

**[JobForge](https://github.com/Likhithpadige-cyber/jobforge)** is a privacy-first
job application assistant. It scores how well a verified candidate profile fits
a job posting with transparent rules, drafts application material in which every
claim cites a fact the candidate has verified, and keeps a person in charge of
every decision.

**Infrastructure and operations work**

- Docker Compose stacks for development, an isolated loopback-only demo, and a
  private single-owner runtime: one loopback edge (Caddy), internal networks
  with no outbound internet, and least-privilege PostgreSQL roles.
- Fail-closed startup checks: required secrets are validated, services refuse
  to serve against the wrong database schema, and a preflight check fails on
  unsafe configuration.
- GitHub Actions CI with linting, type checks, tests, dependency audits,
  full-history secret scanning (Gitleaks, detect-secrets) and image builds;
  actions pinned to commit SHAs.
- Public-key-encrypted backups, verified by restoring into an isolated stack.

**Safety by design**

- **Portfolio project** — there is no hosted public deployment; it runs locally
  or as a private, single-owner install.
- **AI with safety controls** — replay mode is the default, so tests and the
  demo make no calls to a model provider; live AI is opt-in.
- **Human-approved submission** — dry-run by default; nothing is sent without
  an owner's explicit approval.

**Built with:** Python · FastAPI · PostgreSQL · Redis · TypeScript · Next.js ·
React · Docker · GitHub Actions
